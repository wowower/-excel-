# 共达无障碍工具箱

五个本机运行的开源无障碍原型：表达板、轻阅读、字幕工作台、一步任务卡、网页源码检查台。零第三方运行时依赖，没有账号、遥测或识别 API。

## 运行

Windows 双击 [start.bat](./start.bat)，或：

```sh
python start.py
```

访问 http://127.0.0.1:8770/index.html 。启动脚本只绑定本机回环地址。无需 Python 也可打开 [index.html](./index.html)，但推荐使用本地服务以保持一致的存储来源。

## 实现边界

表达板支持文本短语与键盘模拟开关，不包含符号库、眼控或专业语言干预。语音只选择浏览器报告为本地的声音，实际设备能力和声音质量需另行验证。阅读工具不解析 PDF、EPUB 或 OCR，不改写原文。字幕工具校对已有 SRT/WebVTT，不自动转写；导入只保留纯文本及时间。网页检查工具仅输出静态线索，不作 WCAG 符合性或法律判定。

本软件未经过真实残障用户参与的可用性验证、临床验证或全面无障碍认证。不得替代专业辅助技术评估、医疗服务、手语翻译、危险报警或人工审计。完整限制写在各模块及用户指南中。

## 隐私

内容只在本机处理。默认不保存句子、原文、字幕、媒体或源码。主动保存的短语、任务和原文使用 localStorage 明文存储；共用设备可能被查看，清理浏览器可能丢失。应定期安全备份。备份和下载文件可能含敏感内容，不应上传公开仓库。

离线缓存只包含静态应用文件，不缓存用户文件。首次经 localhost 或 HTTPS 正常加载且缓存完成后才能断网打开；直接下载源码也能本地使用。外部来源链接需联网。
