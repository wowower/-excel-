## 已修复的具体问题

- 原先跳转主要内容的锚点可能触发路由回首页，现保持在当前工具并移动焦点。
- 清理本机数据后，任务模块曾可能继续自动保存，现同步关闭持续保存。
- 阅读编辑区尚未应用的草稿曾可能覆盖已保存原文，现按已载入文本保存。
- 静态检查曾可能把 select 的选项文字误作控件名称，现分别检查标签与控件内容。
- 文档初版末段溢出至额外页，已调整并重新渲染确认。

## 未验证

真实残障用户的适用性、外接开关硬件、NVDA/JAWS/VoiceOver 等专业辅助技术、多浏览器与移动设备组合、本地语音的实际声音质量及离线声音输出。当前设备发现 3 个系统本地中文声音，只验证枚举与选择限制，不以此声称所有设备可朗读。

浏览器自检使用合成键盘事件验证扫描与导航逻辑。当前共享页面处于隐藏状态，集成工具尝试转发原生按键时没有产生 keydown 事件，因此原生键盘验收尚未得到可确认结果，不能将合成事件结果改写成实体键盘或外接开关已通过。

未完成完整 WCAG 2.2 符合性审计，也未完成 400% 浏览器缩放的真实辅助技术验证。42 组检查只代表布局尺寸与文本缩放组合，不应改写为全面无障碍通过。未验证所有视频编解码器和真实长视频。不存在临床试验、治疗效果、认证、采购或真实留存数据。

## 复现

运行 `node test-core.cjs` 做核心检查。启动本机服务后打开 `/browser-tests.html`，点击运行五模块自检。查看页面给出的通过数和失败条目。不要在 file 地址下运行跨页面测试；使用本机 HTTP 服务。

页面功能与数据处理通过不等于适合所有人。后续验证应优先邀请当事人选择任务，记录阻碍、偏好、不适用情形与退出意愿，并按输入方式和环境分层呈现结果。
