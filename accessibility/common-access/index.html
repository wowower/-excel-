选短语组成一句话，再选择朗读或大字展示。短语的位置固定，只有你主动修改时才会改变。

正在读取设备本地语音；没有本地语音时仍可大字展示。

常用短语

扫描尚未开始

开始后，焦点停留在这里。按空格或回车选中当前项；方向右键前进。Esc、Tab 或离开此区域会停止扫描。

扫描也包含朗读、撤回、清空和停止。支持模拟空格或回车的外接开关；实际硬件需自行配置和实测。扫描不会控制网页以外的程序。

修改短语

点击“应用”只改变本次页面。记住短语会写入此浏览器明文存储；句子内容不自动保存。不同设备的本地语音可能不同。

05 / 无障碍内容建设

网页检查台

粘贴 HTML 源码，寻找常见结构问题。源码不会被执行，也不会上传。检查只是线索，不能证明页面符合无障碍标准。

不加载图片、iframe、样式或脚本。不处理真实网站的交互、CSS 计算样式、可见性和完整可访问名称算法。所有结论需回到实际页面人工验证。

帮助与数据管理

按适合你的方式使用。

键盘操作

  • Tab / Shift+Tab 在控件之间移动；Enter 或空格激活按钮。
  • 表达板中，方向键移动到相邻短语。扫描区域内，空格或 Enter 选择高亮项；Esc、Tab 或焦点离开即停止。
  • 阅读区域聚焦后，可按左右方向键切换段落。
  • 页面顶部有“跳到主要内容”链接。没有必须按时完成的步骤。

本地语音

只列出浏览器报告为本地的声音。没有可用声音时，表达板的大字、阅读文字与其他工具仍可使用。语音由系统提供，语言、质量和离线可用性需在自己的设备上确认。

离线使用

下载后可打开网页；推荐使用随附的本地启动脚本。通过 localhost 或 HTTPS 访问并完成首次缓存后，可断网继续使用静态功能。外部指南链接需要网络。浏览器能力和本地语音不保证跨设备相同。

备份与恢复

导出包含当前表达板短语、任务卡和你主动记住的阅读内容。字幕、媒体、临时句子和网页源码不进入备份。JSON 可能有敏感内容，请妥善保存。

导入前先校验，确认后替换对应模块。已有内容不会自动合并，建议先备份。

清理本机数据

本机存储没有加密。共用设备上的其他使用者可能查看内容，清理浏览器也可能使记录丢失。
