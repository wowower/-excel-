# 共达无障碍工具箱用户指南

适用版本 0.1.0

## 启动与基本操作

本软件是零第三方运行时依赖的网页工具。Windows 可双击 start.bat，或在目录执行 `python start.py`。该脚本只在本机 127.0.0.1 提供文件服务并打开浏览器；不是向互联网开放服务器。没有 Python 时可直接打开 index.html，但 file 地址的本机存储行为因浏览器而异。

界面顶部可以调整字号及配色；Tab 和 Shift+Tab 移动焦点，Enter 或空格激活按钮。主导航按任务分成五个工具，切换工具会停止扫描和朗读。键盘用户可以用顶部的跳转链接进入当前工具的主要内容。

## 表达板

点击短语组成句子，或者直接输入；可以撤回、清空、大字展示或朗读。自定义短语每行一个，点击应用只改变本次页面，点击记住才写入本机。句子默认不保存。

自动扫描仅在扫描区域聚焦时工作。空格或 Enter 选择当前项，方向右键前进；Esc、Tab、失焦、窗口失去焦点和工具切换均停止扫描。外接开关需要能模拟键盘按键并完成实际配置，软件不会控制其他应用。

朗读只提供系统标记为本地的声音。当前开发设备检测到 3 个中文本地声音，但不保证其他设备可用，也没有完成声音质量或真实使用者听感验证。

## 轻阅读

粘贴原文或导入 UTF-8 TXT，点击开始阅读。每个换行形成一个段落，可前后切换，调整字号、行距、列宽、字间距和背景。编辑区修改只有再次开始阅读后才应用，不会自动替换当前阅读内容。

默认不记住原文。勾选记住后，内容与当前段落位置会保存在此浏览器明文存储中；取消勾选会删除已保存内容。不要把共享设备当成安全私密空间。

## 字幕工作台

打开或粘贴 SRT / WebVTT 后，选择字幕条目，编辑开始、结束和正文。时间可用 `00:00:01.000` 或 SRT 的逗号毫秒格式。整体偏移按整数毫秒执行；若任一结果会为负，整次修改会被拒绝。

可打开本地视频或音频，当前字幕显示在播放器下方。不进行音频转写，也不将字幕烧录到视频。只保留纯文本与时间，导入位置、样式和标签可能丢失并会提示。重叠与速度线索需人工核实，特别是说话人和关键声音。

## 一步任务卡

每行一个步骤，点击开始任务，然后按个人节奏完成、退回或暂停。点击保存后，后续进度会写入本机；暂停不删除位置。可选计时器不会自动完成步骤，关闭页面不会发送后台提醒。

仅用于低风险日常任务。不要据此执行药物剂量、安全操作或必须依赖准确提醒的行动。

## 网页检查台

粘贴 HTML 源码并运行检查。输入不会成为活动页面，也不请求其中的图片、iframe 或脚本。结果是静态线索，不包含页面实际 CSS、动态组件、可见性、完整可访问名称算法或跨页面流程。不能把零线索理解为符合标准。

对比度只计算两种六位十六进制、不透明 sRGB 颜色。计算结果不代表实际网页所有文字都符合要求。

## 保存 备份与删除

帮助页可导出版本化 JSON，包含当前表达板、当前任务及主动记住的原文；不含媒体、字幕、临时句子和网页源码。导入前先校验，确认后替换对应模块，建议先导出当前状态。遇到损坏存储时暂停写入，不悄悄覆盖。

数据与网站地址、端口、浏览器和设备关联。换地址可能看不到旧内容，应通过导出和导入迁移。软件不加密本地数据，不自动同步 GitHub。清理本机数据需要确认，并会停止后续任务自动保存；本次页面临时内容仍可继续使用。

## 已知限制与反馈

尚未完成真实残障用户可用性测试、专业 NVDA 或 VoiceOver 测试、真实外接开关、多浏览器和全部媒体格式验证；没有无障碍认证或临床验证。离线能力取决于已下载文件或已完成首次静态缓存，外部文献需要网络。

反馈建议说明设备、浏览器、辅助方式、想完成的任务、实际阻碍及是否允许使用合成内容复现。不要在公开 GitHub 问题中上传个人沟通文本、健康资料、身份信息或未获授权的音视频。
