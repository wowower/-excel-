# 安心血压 · Home BP Journal

一个用于成人家庭血压记录的开源小工具。目标很具体：帮助人们规范留存读数，把有用的记录带到诊室。**这是未经临床验证的记录工具，不是医疗器械，不诊断、不推荐药物或剂量。**

## 立即使用

下载本目录，双击 [index.html](./index.html)。无需安装、账号、构建或网络。也可在本目录运行：

```sh
python -m http.server 8766 --bind 127.0.0.1
```

打开 http://127.0.0.1:8766 。使用同一个地址和浏览器保存、查看记录；不同来源、浏览器或文件路径的存储可能互不相通。推荐 HTTP 本地服务而非依赖浏览器不统一的 `file://` 存储行为。

## 功能

- 日期、时间、早晚时段、收缩压、舒张压、可选脉搏与备注。
- 输入读数时即时显示提示；症状提示优先于读数，任一血压分量达到边界即提示联系医疗人员。
- 任意连续 7 个日历日的趋势、记录数和等权算术平均；首日可排除，原始记录始终保留。
- 每日早晚记录数量概览；不以覆盖数量判断测量是否合格。
- 打印所选窗口的就诊摘要，可使用浏览器“另存为 PDF”。
- 本地 JSON 备份与合并导入；有冲突则整体拒绝。删除和清空需确认。
- 合成示例与个人数据隔离；示例模式禁用保存、导入、导出与删除。
- 无第三方依赖、外部字体、追踪、遥测、账号及数据上传接口。

## 医疗依据与规则

参考资料核对于 2026-11-11，详见 [SOURCES.md](./SOURCES.md)。测量步骤和高读数提示参考 AHA；7 天窗口和首日排除参考 NICE，但不据此自动诊断。不同地区和个人情况的诊疗标准不同。

本工具保守地在 `收缩压 >= 180 OR 舒张压 >= 120` 时显示高读数提示。**症状勾选无论读数多少都显示急救提示**；较低读数不能排除急症。应用没有低血压、心律失常、妊娠高血压等专门风险算法，没有“安全”判定。

一般输入允许收缩压 40–300、舒张压 20–200 mmHg、脉搏 20–250 次/分钟，且收缩压大于舒张压。这是减少输错的工程校验，绝不是健康范围或硬件能力声明。超出输入范围、有不适或对读数有疑问时，核对设备并寻求医疗帮助，不要因为无法录入而延误就医。

使用者自行选择时间和时段，应用不检测血压、不读取设备、不验证两次测量间隔或姿势。计时器不在关闭页面后发送通知。打印报告不构成经过验证的临床报告。

## 隐私与可靠性

健康记录以明文保存在当前来源的 `localStorage`，不应在不可信共用设备上保存。没有加密或认证；浏览器扩展、设备访问者、恶意同源脚本均可能读取。浏览器清理、隐私模式、空间限制或路径变化会导致丢失，请定期导出并安全保管备份。GitHub 只包含源代码、测试和合成示例，不包含真实健康数据。

已有数据无法解析时暂停写入，避免静默覆盖。存储失败不会声称保存成功。导入最多 10 MB、10,000 条，先验证再合并；同 ID 不同内容整体拒绝。不自动跨设备同步；多标签页仅提供基础存储事件同步，不保证并发编辑事务安全。

## 开发与测试

```sh
node test-engine.cjs
```

零 npm 依赖。核心规则测试涵盖阈值两侧、症状优先、7 天边界、首日排除、闰日、无数据平均值、坏备份和重复编号。浏览器验证另检查录入、持久化、示例隔离、导出内容、打印摘要与移动布局。
